# Mapa Fn de QMK en ZMK

Esta revisión completa las 68 posiciones de Fn y las dos bases a partir del
QMK instalado. Las letras de Colemak y QWERTY se conservan. Las únicas cinco
excepciones respecto a Fn QMK son los controles inalámbricos acordados en
las posiciones físicas Colemak W/F/P/G/D.

| Fn + posición Colemak | Acción |
| --- | --- |
| Caps / Q | Brillo − / + |
| Tab | Siguiente modo RGB |
| A | Tono + |
| Shift / <> | Saturación − / + |
| Esc | Encender/apagar RGB |
| Tecla a la izquierda / derecha de ↑ | Velocidad − / + |
| ↑ / ↓ | Volumen + / − |
| ← / → | Canción anterior / siguiente |
| Espacio derecho | Play/Pause |
| Enter derecho | Mute |
| Espacio izquierdo | Captura de pantalla |
| J / L / U / Y / Ñ | Presets P1 / P2 / P3 / P4 / P5 |
| W / F / P | Perfiles Bluetooth 1 / 2 / 3 |
| G | Borrar emparejamiento del perfil seleccionado |
| D | Preferir USB / Bluetooth |

Las posiciones físicas son iguales desde QWERTY. Los controles de Fn emiten
los mismos códigos de letras, puntuación, navegación y multimedia que QMK.
No se reemplazan por transparencia cuando QMK tiene una letra explícita.

## Presets

Un toque carga al soltar; mantener Fn y la tecla durante dos segundos guarda.
Se guardan color base (tono/saturación/brillo), efecto, velocidad y encendido,
en cinco registros versionados con CRC independientes de los ajustes Bluetooth.
Una ranura sin guardar no cambia el RGB. Las ranuras iniciales son nuevas en
ZMK; los registros EEPROM del QMK cableado no se copian a la memoria ZMK.

Los registros se guardan en la central. Al cargar se envía una configuración
absoluta a ambas mitades mediante el transporte RGB global de ZMK. El trabajo
de guardado se ejecuta en la cola del sistema, evitando escribir memoria desde
el hilo de entrada Bluetooth. Soltar Fn antes de dos segundos evita guardar.

Esta etapa conserva los cuatro efectos RGB nativos de ZMK. Los seis efectos
QMK, colores inversos por tecla, luces de Fn y perrito se migrarán después.
La pantalla central sí identifica CLMK, QWRTY y Lower.

## Perfiles visibles con USB

El indicador muestra U/B (preferencia USB/Bluetooth), el número del perfil
seleccionado 1–5 y un símbolo de la salida efectiva. Por ejemplo B1 con símbolo
USB indica preferencia Bluetooth en perfil 1, pero sin conexión activa a ese
equipo se sigue usando USB. Cambiar el perfil no exige borrar su emparejamiento.

El firmware anterior mostraba únicamente la salida efectiva. Con USB y un
perfil Bluetooth desconectado, ocultaba los cambios de perfil/preferencia.
La prueba inicial basada en esa pantalla no confirmaba los atajos.

Estado: compilación y verificaciones aprobadas en [CI 38633460508](https://github.com/FelipeCris/Crisboard/actions/runs/38633460508), fuente `b47294b2579b5e3e2466426653e33704becf9723`. Ambas mitades cargadas y verificadas por lectura. El usuario confirmó escritura, controles Fn y cambio de base; falta confirmar los cinco presets.

Se compararon las 204 asignaciones enlazadas. La base recompilada reproduce todo el UF2 instalado al restaurar únicamente el orden de dos conjuntos nativos de dos referencias de dispositivos en la izquierda; la derecha coincide exactamente. Ningún otro byte se acepta como diferente. La generación de esos conjuntos ahora conserva un orden estable. Las imágenes de regreso incluidas son las anteriores exactas y verificadas.

La izquierda agrega 1.860 bytes de flash y 368 bytes de RAM; la derecha agrega 176 bytes de flash y mantiene su RAM. Los cinco presets nuevos guardan ocho bytes útiles cada uno en NVS, que administra páginas y registros adicionales. La actualización no carga `settings_reset` ni escribe ajustes o bootloader.

Para probar: escritura y Fn en ambas bases; brillo, tono, saturación, modo y velocidad; volumen, canciones, Play/Pause y Mute; guardar/cargar J/L/U/Y/Ñ y conservarlos al reiniciar; perfiles W/F/P y salida D; voltaje en ambas pantallas. No es necesario borrar emparejamientos con Fn + G.
